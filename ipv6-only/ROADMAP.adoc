== Notes

=== Design Principles

* Pure Rust implementation (no C dependencies)
* Zero-copy parsing where possible
* Async-ready architecture
* WASM compatibility considered

=== Non-Goals

* IPv4 support (this is ipv6-**only**)
* GUI application (CLI and library focus)
* Windows-specific features (POSIX-first)
