= Contributing to ipv6-site-enforcer
:toc: left
:toclevels: 3

`+ipv6-site-enforcer+` is the site-level half of `+ipv6-tools+`: it
validates that a public-facing site serves IPv6 correctly (AAAA records,
IPv6 socket bind, HTTP over IPv6) and ships the Kubernetes manifests that
deploy the check alongside Jool NAT64/DNS64 translation.

== Getting started

[source,bash]
----
git clone https://github.com/hyperpolymath/ipv6-site-enforcer.git
cd ipv6-site-enforcer

# Reproducible shell
guix develop
----

== Repository layout

[source,text]
----

----

== Everyday commands

[source,bash]
----
just            # list recipes
just validate   # kubectl --dry-run=client over manifests/*.yaml
just deploy     # apply namespace, configmap, deployment, service, networkpolicy
just status     # show cluster state for the ipv6-enforcer namespace
just test-dns64 example.com   # exercise DNS64 resolution from inside the pod
----

== Making changes

. Fork the repository and branch from `+main+`.
. Follow Conventional Commits: `+type(scope): description+`, with a body
  explaining what changed and why.
. Sign off every commit (`+git commit -s+`); GPG-signed commits are
  preferred.
. Keep manifests declarative: every `+manifests/*.yaml+` change must pass
  `+just validate+` and keep the container image pinned by digest.
. Submit a pull request and describe how you validated the change.

== Documentation format

AsciiDoc is the canonical documentation format, as it is across the
`+ipv6-tools+` monorepo. Write new documents as `+.adoc+`; Markdown is
allowed only where a platform requires it (issue templates, agent
configs, and any README shim a platform demands). The rule, the exception
list, and the migration record are in
link:../docs/documentation-format-policy.adoc[the documentation format
policy].

== Security

Report vulnerabilities privately through
https://github.com/hyperpolymath/ipv6-site-enforcer/security/advisories/new[GitHub
Security Advisories] — never in a public issue. See
link:SECURITY.adoc[SECURITY.adoc] for the disclosure process.
