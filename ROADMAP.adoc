= IPv6 Tools Roadmap
:toc:
:toclevels: 3

== Overview

IPv6 Tools is a monorepo containing network administration and security tools focused on IPv6 policy enforcement.

== Components

=== ipv6-only (50% complete)

*Status:* Active development +
*Purpose:* IPv6-only network enforcement tool

*Current features:*
- Basic network detection
- IPv4 traffic blocking rules

*Planned improvements:*
- Enhanced policy configuration
- Integration with systemd-networkd
- Comprehensive logging

=== ipv6-site-enforcer (30% complete)

*Status:* Early development +
*Purpose:* Site-wide IPv6 policy enforcer for enterprise networks

*Current features:*
- Policy definition framework
- Basic enforcement engine

*Planned improvements:*
- Multi-site policy distribution
- Real-time monitoring dashboard
- Compliance reporting
